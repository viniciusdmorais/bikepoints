## 🏁 Sobre o Projeto

O **BikePoints Race** nasceu de uma ideia simples:

> “Meus amigos precisavam somar pontos para descobrir quem estava indo mais de bicicleta ao trabalho.”

Mas a ideia evoluiu 😎

Hoje o projeto conta com:

✅ Sistema de pontuação online  
✅ API própria em Node.js  
✅ Banco SQLite  
✅ Persistência de dados  
✅ Frontend animado estilo mini game  
✅ Deploy completo online  
✅ GitHub Pages + Render
